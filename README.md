# StyleSphere
StyleSphere is a fashion e-commerce website developed as a web development project. The website allows users to browse fashion products, view product details and search for stores location.

## Features

- Home page
- Product browsing
- Product details
- Store location page
- About Us / Team page
- Product data stored using JSON

## Technologies Used

- HTML
- CSS
- JavaScript
- JSON
